# WorthBuild

**Before you build the business, know if it’s worth your money.**

This repository contains the first static MVP of WorthBuild.

## Included
- Premium responsive landing page
- Explore Businesses
- Country → region/state → city location model
- Business project pages
- WorthScore breakdown
- Help Me Choose matcher
- Worth It? idea analysis
- Compare
- Project Room
- Checkout UI
- SEO-ready title and description
- Demo/evidence-pending labeling

## Trust principle
**Trust > AI. Evidence > Claims.**

The current project catalog and scores are illustrative demo content. They are not verified financial forecasts, investment advice, or guarantees of profit.
